What to compare

Open a thought, then a connection. Read the note beside the graph. Below each map, a writing sample shows paragraphs, a highlight, a quote, and a margin note.

My preferred base is Atlas: the selected node is clear, and the map has enough space to work as the main way into the notes. Reading offers a useful comparison for a quieter title and smaller page.

All three use shared styles and the same Markdown samples. On a phone, the fixed map scrolls sideways and the selected note opens below it.
